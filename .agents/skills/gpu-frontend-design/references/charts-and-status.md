# 实时图表与数据状态评审

**读取条件** 为实时指标、库存新鲜度或多卡对比设计或修改界面时使用。

1. 指定每条序列的稳定标识、单位、采样时间和时区。GPU 百分比与显存容量使用各自的单位，在图例及提示中保持一致。
2. 将缺样表示为断点或缺失值。上次采集成功的时间、最近一次请求的结果与图上最后一个有效数据点分别取值。采集失败时保留旧值及其时间。
3. 区分机型售卖状态、给定组合的可开状态及未知值。仅有可调度布尔值时不显示推断出来的剩余卡数。
4. 明确刷新策略。追加新采样、去重重复时间戳，保留卡选择、缩放区间和键盘焦点。用户点“回到最新”时才主动重置历史视野。
5. 评审窄屏和辅助阅读。多条曲线提供可选择的图例、每张卡的文字摘要和最近采样时间。使用颜色之外的标签区分状态。
6. 覆盖跨实例切换时迟到的响应、某一张卡断采和完整连接恢复三个交互。逐项记录实际可见结果。
